# 4장. 비교표와 단계별 안내

## 학습 목표

- 질문의 성격에 따라 텍스트, 표, 도식 중 적절한 형식을 선택할 수 있다
- 비교 기준을 먼저 정하고 사실과 의견을 구분할 수 있다
- 근거 없는 점수나 평가를 요구하지 않을 수 있다

## 개념 설명

비교는 학습에서 가장 자주 쓰는 사고 도구다. 두 학습법 중 무엇이 나은지, 두 개념이 어떻게 다른지를 물을 때 비교표만큼 효과적인 형식은 드물다. 하지만 비교표가 유용해지는 조건이 있다. 비교 기준이 먼저 정해져 있어야 한다는 것이다. 기준 없이 만든 표는 항목 나열에 그치고, 기준이 있으면 판단의 근거가 된다.

비교 기준을 정할 때는 측정 가능한 것부터 고른다. 학습법을 비교한다면 학습목표, 소요 시간, 비용, 복습 용이성 같은 기준이 쓸모 있다. 이런 기준은 각 항목에 대해 확인할 수 있는 사실에 가깝다. 반대로 "재미"나 "효과" 같은 기준은 사람마다 달라서 표에 넣기 어렵다. 꼭 넣고 싶다면 "설문에서 reported된 만족도"처럼 근거를 함께 적어야 한다.

사실과 의견을 구분하는 것도 비교표의 핵심이다. "독서는 비용이 들지 않는다"는 도서관 이용을 전제로 한 사실 진술에 가깝고, "영상 강의가 더 재미있다"는 의견이다. 표에 쓸 때는 의견 칸을 따로 두거나, 의견임을 표시한다. AI에게 비교표를 요청할 때 "근거 없는 점수는 붙이지 마."라는 제약을 거는 이유가 여기에 있다. AI는 요청하지 않은 점수나 별점을 그럴듯하게 만들어내는 경우가 있기 때문이다.

단계별 안내는 비교와 짝을 이룬다. 비교로 방향을 정했다면, 단계별 안내로 실행한다. Intelligent UI 환경에서는 단계별 안내가 버튼이나 체크리스트 같은 대화형 요소로 나올 수 있다. 지원되지 않는 환경에서는 번호 목록 텍스트로 같은 내용을 전달한다. 형식은 달라도 구조는 같다. 순서가 있고, 각 단계의 완료 조건이 분명하다.

## 언제 쓰는가

- 두 가지 이상의 선택지 중 하나를 골라야 할 때
- 개념 두 개의 차이점을 정리해야 할 때
- 순서를 따라 해야 하는 작업을 안내할 때

## 사전 준비

- 3장에서 만든 다섯 요소 질문 구조
- 비교하고 싶은 주제 (예: 독서와 영상 강의)
- 메모장

## 단계별 실습

1단계. 비교 기준을 먼저 정한다. 주제(예: 독서와 영상 강의)에 대해 비교 기준 4개를 메모한다. 예: 학습목표, 시간, 비용, 복습 용이성.

2단계. 비교표를 요청한다. 아래 프롬프트 1을 입력한다. 결과 표에 근거 없는 점수나 별점이 있는지 확인한다.

3단계. 사실과 의견을 구분한다. 표의 각 셀을 보고 사실에 가까운 것과 의견에 가까운 것을 표시해 본다.

4단계. 기준을 바꿔 재평가한다. 기준 중 하나를 바꾸거나 추가해 다시 요청한다. 예: "비용 기준을 빼고 휴대성을 넣어줘." 결과가 어떻게 달라지는지 기록한다.

5단계. 단계별 안내로 연결한다. 비교 결과 선택한 쪽에 대해 "선택한 학습법의 1주일 실행 계획을 단계별로 안내해줘."라고 요청한다.

## 복사해서 쓰는 프롬프트

프롬프트 1. 비교표 요청

```
독서와 영상 강의의 장단점을 학습목표·시간·비용·복습 용이성으로 비교해줘. 근거 없는 점수는 붙이지 마.
```

프롬프트 2. 단계별 안내 요청

```
위 비교에서 선택한 학습법으로 1주일 학습 계획을 세워줘. 매일 할 일을 단계별로 안내하고, 각 단계의 완료 조건을 함께 적어줘.
```

## 입력 예시

프롬프트 1을 입력하면 4개 기준에 대한 비교표가 돌아온다. 셀에 "독서: 도서관 이용 시 무료" 같은 사실 진술과 "집중도에 따라 다름" 같은 조건부 진술이 섞여 있을 수 있다.

## 성공 예시

비교 기준이 명확하고, 근거 없는 점수가 없으며, 사실과 의견이 구분된 표를 받는다. 이어서 단계별 안내까지 받아 비교에서 실행으로 자연스럽게 연결된다.

## 실패 예시

기준 없이 "독서와 영상 강의 중 뭐가 좋아?"라고 묻고, AI가 붙인 별점(예: 독서 4점, 영상 5점)을 근거로 선택한다. 근거 없는 점수는 AI가 지어낸 것일 수 있다.

## 오류 해결

- 근거 없는 점수가 나올 때: "점수와 별점을 빼고 사실만으로 다시 정리해줘."라고 요청한다.
- 표가 너무 클 때: 기준을 3개로 줄이거나, 항목을 2개로 줄여 다시 요청한다.
- 의견과 사실이 섞여 있을 때: "각 셀에 사실인지 의견인지 표시해줘."라고 요청한다.

## 완료 점검

- [ ] 비교 기준을 먼저 정하고 표를 요청할 수 있다
- [ ] 표에서 사실과 의견을 구분할 수 있다
- [ ] 근거 없는 점수를 요구하지 않고, 나오면 제거를 요청할 수 있다

## 확인 문제

1. 비교표를 요청할 때 "근거 없는 점수는 붙이지 마."라는 제약을 거는 이유는? 정답: AI가 근거 없이 그럴듯한 점수나 별점을 만들어낼 수 있기 때문이다.

2. "영상 강의가 더 재미있다."는 비교표의 어디에 들어가야 하는가? 정답: 의견 칸에, 의견임을 표시해서. 사람마다 다른 주관적 판단이므로 사실과 구분해야 한다.
