# 7장. AI 답변 검증과 개인정보

## 학습 목표

- 환각, 출처 오류, 개인정보 위험을 식별할 수 있다
- 검증 가능한 주장과 그렇지 않은 주장을 구분할 수 있다
- 외부 출처를 직접 열어 확인하는 습관을 기를 수 있다

## 개념 설명

AI 답변을 검증해야 하는 이유는 세 가지 위험 때문이다. 첫째는 환각이다. AI가 그럴듯하지만 사실이 아닌 내용을 만들어내는 현상이다. 날짜, 숫자, 인용에서 자주 발생한다. 둘째는 출처 오류다. 출처를 제시했는데 링크가 열리지 않거나, 내용과 무관하거나, 존재하지 않는 문서인 경우다. 셋째는 개인정보 위험이다. 학습용 대화에 주민번호, 계좌번호, 주소 같은 정보를 입력하면 그 정보가 대화 기록에 남는다.

검증의 출발점은 주장 분리다. AI 답변을 읽으며 "검증 가능한 주장"과 "검증이 필요 없는 부분"을 나눈다. 검증 가능한 주장은 날짜, 숫자, 기관명, 인용처럼 외부에서 확인할 수 있는 것이다. 의견, 비유, 일반적인 조언은 검증 대상이 아니다. 분리한 뒤에는 확인이 필요한 순서대로 표를 만든다. 영향이 큰 주장부터 확인한다. 예를 들어 금액 계산의 근거가 되는 이자율은 먼저, 비유적 표현은 나중에 확인한다.

외부 출처는 반드시 직접 열어 확인한다. AI가 제시한 링크를 클릭해 실제 내용이 답변과 일치하는지 본다. 링크가 열리지 않으면 미확인으로 기록한다. 검색으로 같은 내용을 찾을 수 있으면 교차 확인한다. 확인하지 못한 주장은 "미확인"이라고 명시한다. 모르는 것을 모른다고 적는 것이 검증 기록의 핵심이다.

개인정보 보호는 검증만큼 중요하다. 실습에 쓸 데이터는 가상의 것으로 만든다. 실제 이름, 실제 계좌, 실제 주소는 어떤 경우에도 입력하지 않는다. 화면을 캡처해 공유할 때도 계정명, 대화 제목, 개인정보가 보이지 않는지 확인한다. 이 책의 모든 예제는 가상 데이터로 구성돼 있다.

## 언제 쓰는가

- AI 답변의 숫자, 날짜, 인용을 그대로 쓰기 전
- 다른 사람에게 전달할 자료를 만들기 전
- 실습 예제에 쓸 데이터를 준비할 때

## 사전 준비

- 1~6장에서 받은 AI 답변 중 하나 (검증 대상)
- 웹브라우저 (출처 확인용)
- 메모장 (검증 기록표용)

## 단계별 실습

1단계. 검증 대상을 고른다. 이전 장에서 받은 답변 중 숫자나 주장이 들어간 것을 하나 고른다.

2단계. 주장을 분리한다. 아래 프롬프트 1을 입력해 검증 가능한 주장만 표로 정리한다.

3단계. 외부 출처를 직접 연다. 표의 각 주장에 대해 AI가 제시한 출처나 직접 검색한 출처를 열어 내용 일치를 확인한다.

4단계. 검증 기록표를 완성한다. 확인됨, 미확인, 오류로 구분해 기록한다. 오류가 있으면 정정 내용을 함께 적는다.

5단계. 개인정보를 점검한다. 지금까지의 실습 대화에 실명, 연락처, 계좌 같은 정보가 들어갔는지 확인한다. 들어갔다면 해당 대화를 삭제하거나 기록에서 지운다.

## 복사해서 쓰는 프롬프트

프롬프트 1. 주장 분리 요청

```
방금 답변의 검증 가능한 주장만 추려 원문 확인이 필요한 순서대로 표로 정리해줘. 확인되지 않은 것은 미확인이라고 써줘.
```

프롬프트 2. 가상 데이터 요청

```
위 실습에 쓸 가상 데이터를 만들어줘. 실존 인물이 아닌 가상의 이름, 가상의 금액으로 구성하고, 가상 데이터임을 표에 표시해줘.
```

## 입력 예시

6장에서 만든 퀴즈 결과나 5장의 계산 결과를 검증 대상으로 쓴다. 프롬프트 1을 입력하면 주장, 출처, 확인 상태 열이 있는 표가 돌아온다.

## 성공 예시

검증 기록표가 완성되고, 확인된 주장과 미확인 주장이 구분돼 있다. 예: "이자율 5% → 출처(은행 공시)에서 확인됨 / 역사적 일화 → 출처 없음, 미확인."

## 실패 예시

AI가 제시한 링크를 열어보지 않고 "출처 있음"으로 기록한다. 또는 실명을 그대로 실습 예제에 입력한다.

## 오류 해결

- 링크가 열리지 않을 때: 미확인으로 기록하고, 검색으로 같은 기관의 공식 문서를 찾아 교차 확인한다.
- 출처와 내용이 다를 때: 오류로 기록하고, 답변의 해당 부분을 정정해 다시 요청한다.
- 개인정보를 이미 입력했을 때: 해당 대화를 삭제하고, 이후에는 가상 데이터를 쓴다.

## 완료 점검

- [ ] 검증 가능한 주장과 그렇지 않은 주장을 구분할 수 있다
- [ ] 외부 출처를 실제로 열어 확인했다
- [ ] 확인되지 않은 것을 미확인이라고 기록했다
- [ ] 실습에 가상 데이터만 사용했다

## 확인 문제

1. AI가 제시한 출처 링크가 열리지 않을 때 올바른 기록은? 정답: 미확인. 열리지 않는 출처는 확인된 것이 아니다.

2. 실습 예제에 실명 대신 가상 데이터를 써야 하는 이유는? 정답: 입력한 개인정보가 대화 기록에 남아 유출 위험이 있기 때문이다.
