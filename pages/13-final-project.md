# 종합 실습

8장의 최종 프로젝트를 따라 하기 전에, 지금까지의 학습을 한 번에 점검하는 종합 실습이다. 아래 순서대로 진행하고 각 단계의 결과를 기록한다.

## 실습 1. 개인 맞춤형 학습 도구 3종 만들기

주제 하나를 정한다 (예: 예금 이자, 분수 덧셈, 일차함수). 같은 주제로 세 도구를 만든다.

1. 개념 비교표: 4장의 방법을 적용한다. 비교 기준 3~4개를 정하고, 근거 없는 점수를 붙이지 않는다. 사실과 의견을 구분한다.
2. 실습 체크리스트: 1~7장의 완료 점검 항목 중 주제 학습에 필요한 것을 모아 체크리스트로 만든다.
3. 변수 조절 계산기: 5장의 설계도(입력값, 단위, 공식, 예외 조건)를 적용한다. 대화형 UI가 지원되지 않으면 표와 계산 절차로 만든다.

## 실습 2. 검증 기록 작성

7장의 검증 기록표 형식을 따라 세 도구의 내용을 검증한다.

| 도구 | 검증 대상 | 확인 방법 | 결과 |
|------|----------|----------|------|
| 개념 비교표 | 각 셀의 사실 진술 | 외부 출처 대조 | 확인됨 / 미확인 |
| 실습 체크리스트 | 항목의 실행 가능성 | 직접 따라 하기 | 확인됨 / 수정 필요 |
| 변수 조절 계산기 | 세 개 수치 | 손계산 검산 | 일치 / 불일치 |

## 실습 3. 출처 확인표와 기능 가용성 점검표

출처 확인표: 실습에 사용한 외부 출처의 제목, URL, 접근일을 기록한다. 열리지 않는 링크는 미확인으로 표시한다.

기능 가용성 점검표: 내 환경의 요금제, 적용 모델, Chat 탭 여부, 대화형 요소 표시 여부를 기록한다 (2장 실습 결과 활용).

## 실습 4. 제3자 재현 확인

만든 패키지를 다른 사람에게 전달하고 처음부터 따라 하게 한다. 막히는 지점을 기록하고, 각 지점에 대해 대체 경로(표와 텍스트로 같은 학습을 하는 방법)를 제공한다.

## 제출 점검

- [ ] 학습 도구 3종이 가상 데이터로 완성됐다
- [ ] 검증 기록표에 모든 항목의 확인 상태가 기록됐다
- [ ] 출처 확인표와 기능 가용성 점검표를 작성했다
- [ ] 제3자가 같은 순서로 재현했거나, 막힌 지점의 대체 경로를 제공했다
