# 2장. Chat 탭과 기능 확인

## 학습 목표

- 내 계정에서 Intelligent UI 지원 여부를 안전하게 확인할 수 있다
- Chat 탭과 Work 탭의 차이를 구분할 수 있다
- 지원되지 않는 환경에서의 대안을 설명할 수 있다

## 개념 설명

Intelligent UI는 모든 화면에서 똑같이 동작하지 않는다. 공식 발표에 따르면 2026년 10월 7일 유료 플랜(Plus, Pro, Business, Enterprise)부터 Chat 탭에 순차 공개됐고, 무료와 Go 플랜은 10월 8일부터 순차 배포됐다. 순차 배포라는 말의 뜻은 명확하다. 같은 날 가입한 두 사용자의 화면이 다를 수 있고, 어제 안 되던 기능이 내일 갑자기 될 수도 있다는 것이다.

지원 범위를 가르는 기준은 세 가지다. 첫째는 요금제다. 유료 플랜은 GPT-6 Sol, 무료와 Go 플랜은 GPT-6 Luna라는 모델이 적용된다. 둘째는 화면 위치다. Intelligent UI는 Chat 탭에서만 동작한다. Work 탭이나 Codex, 음성 대화, 구형 데스크톱 앱에서는 지원되지 않는다. 셋째는 모델 설정이다. 유료 플랜의 추론 모델(GPT-6 Astra)에서는 동작하지 않으며, Instant부터 Extra High까지의 설정에서 동작한다. 이 조건들은 2026년 10월 10일 공식 도움말에서 직접 확인한 내용이며, 이후 변경될 수 있다.

여기서 중요한 태도가 있다. 내 화면에 기능이 없다고 해서 계정에 문제가 생긴 것은 아니다. 순차 배포 중이거나, 지원되지 않는 탭에 있거나, 설정이 맞지 않는 경우다. 무리하게 설정을 바꾸거나 비공식 우회 방법을 쓰지 말고, 공식 안내에 따라 기다리거나 대안을 쓰면 된다. 이 장의 실습은 바로 그 확인 절차다.

지원되지 않는 환경에서도 학습은 계속된다. 대화형 계산기가 안 나오면 Markdown 표와 계산 절차를 요청하면 되고, 버튼이 안 눌리면 단계별 안내 텍스트로 같은 내용을 배울 수 있다. 이 책의 모든 실습에는 이런 대체 경로가 포함돼 있다.

## 언제 쓰는가

- 처음 이 책의 실습을 시작하기 전, 내 환경의 지원 여부를 확인할 때
- 대화형 요소가 나오지 않아 원인을 파악하고 싶을 때
- 다른 사람에게 실습을 안내하기 전, 그 사람의 환경을 점검할 때

## 사전 준비

- ChatGPT 계정 (로그인 상태)
- 웹브라우저의 Chat 탭 화면
- 메모장 (확인 결과를 기록용)

## 단계별 실습

1단계. 화면 위치를 확인한다. 지금 보고 있는 화면이 Chat 탭인지 확인한다. Work 탭이나 다른 탭에 있다면 Chat 탭으로 이동한다.

2단계. 모델과 설정을 확인한다. 화면에 표시된 모델 이름과 설정(Instant, High 등)을 메모한다.

3단계. 대화형 요소를 요청해 본다. 아래 프롬프트 1을 입력하고, 버튼이나 입력 칸 같은 대화형 요소가 나타나는지 기록한다.

4단계. 결과를 정리한다. 대화형 요소가 나오면 지원되는 환경, 나오지 않으면 2장의 대체 경로(표와 계산 절차 요청)를 사용하기로 기록한다. 실제 화면 미확보: 이 책의 그림은 모식도이며 실제 UI가 아니다.

## 복사해서 쓰는 프롬프트

프롬프트 1. 지원 여부 확인하기

```
내가 사용하는 화면에서 대화형 요소를 볼 수 있는지 확인하는 단계와, 지원되지 않을 때 텍스트만으로 학습하는 대안을 알려줘.
```

프롬프트 2. 대체 경로 요청하기

```
대화형 계산기가 지원되지 않는 환경을 가정하고, 같은 내용을 Markdown 표와 단계별 계산 절차로 설명해줘.
```

## 입력 예시

프롬프트 1을 Chat 탭에 입력한다. 모델이 현재 화면에서 확인할 수 있는 단계(모델 이름 확인, 설정 확인, 테스트 요청)를 안내하고, 지원되지 않을 때의 대안을 함께 알려준다.

## 성공 예시

내 환경의 지원 여부를 말로 설명할 수 있다. 예: "내 계정은 무료 플랜이라 GPT-6 Luna가 적용되고, Chat 탭에서 대화형 요소가 표시됐다." 또는 "내 화면에서는 아직 대화형 요소가 나오지 않아 표와 계산 절차로 실습을 진행하기로 했다."

## 실패 예시

지원되지 않는 것을 계정 오류로 착각하고 불필요한 조치를 한다. 예: 로그아웃을 반복하거나, 비공식 설정 변경 방법을 찾아본다. 또는 Chat 탭이 아닌 Work 탭에서 실습하며 기능이 없다고 판단한다.

## 오류 해결

- Work 탭에서 대화형 요소가 안 나올 때: 정상이다. Chat 탭으로 이동한다.
- 음성 대화에서 안 나올 때: 지원되지 않는 방식이다. 텍스트 Chat으로 전환한다.
- 설정이 Astra로 돼 있을 때: Instant~Extra High 범위의 설정으로 바꾼다.
- 순차 배포로 아직 안 될 때: 기다리거나 대체 경로를 쓴다.

## 완료 점검

- [ ] Chat 탭과 Work 탭의 차이를 구분할 수 있다
- [ ] 내 계정의 요금제와 적용 모델(Sol/Luna)을 말할 수 있다
- [ ] 지원되지 않을 때의 대안(표와 계산 절차 요청)을 설명할 수 있다

## 확인 문제

1. Intelligent UI가 동작하는 곳은? (1) Chat 탭 (2) Work 탭 (3) 음성 대화. 정답: (1). 공식 도움말 기준 2026-10-10 현재 Work 탭, 음성, 구형 데스크톱 앱은 미지원이다.

2. 무료 플랜 사용자의 화면에 대화형 요소가 나오지 않을 때 올바른 대응은? 정답: 순차 배포 중일 수 있으므로 기다리거나, 표와 계산 절차를 요청하는 대체 경로로 실습을 계속한다.
