# 용어집·출처

## 용어집

- Intelligent UI: GPT-6가 질문의 성격에 따라 텍스트, 표, 차트, 버튼, 계산기 같은 대화형 요소를 골라 답하는 기능. 2026년 10월 7일 공개 시작.
- GPT-6 Sol: 유료 플랜(Plus, Pro, Business, Enterprise)에 적용되는 GPT-6 모델.
- GPT-6 Luna: 무료 및 Go 플랜에 적용되는 GPT-6 모델.
- GPT-6 Astra: Pro 플랜의 추론 모델. Intelligent UI 미지원 (2026-10-10 기준).
- Chat 탭: Intelligent UI가 동작하는 ChatGPT의 대화 화면. Work 탭과 구분된다.
- Work 탭: Intelligent UI가 적용되지 않는 업무용 화면 (2026-10-10 기준).
- 환각: AI가 그럴듯하지만 사실이 아닌 내용을 만들어내는 현상.
- 순차 배포: 계정, 지역, 클라이언트별로 기능을 나누어 공개하는 방식. 같은 시점에도 사용자별 화면이 다를 수 있다.
- 검증 기록표: AI 답변의 주장을 확인됨·미확인·오류로 구분해 기록한 표.
- 대체 경로: 대화형 요소가 지원되지 않는 환경에서 표와 텍스트로 같은 학습을 하는 방법.
