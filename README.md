## 책 소개

2026년 10월 7일, OpenAI는 GPT-6와 함께 인텔리전트 UI(Intelligent UI)를 ChatGPT의 Chat 탭에 공개하기 시작했다. 이제 ChatGPT는 문장으로만 답하지 않는다. 질문에 따라 표, 버튼, 계산기, 대화형 설명을 곁들여 답한다.

이 책은 AI 초보자, 학생, 직장인, 교사를 위한 입문서다. 선수지식은 계정 생성과 웹브라우저 사용뿐이다. 8개 장의 실습을 따라가면 대화만으로 표와 계산기, 학습 도구를 만들고, 그 결과를 직접 검증하는 법까지 익힐 수 있다. 최종 프로젝트에서는 개인 맞춤형 학습 도구 3종(개념 비교표·실습 체크리스트·변수 조절 계산기)과 검증 기록을 완성한다.

각 장은 개념 설명, 준비물, 3~5단계 실습, 복사해서 쓰는 프롬프트 2개 이상, 성공·실패 예시, 오류 해결, 완료 점검, 확인 문제 2문항, 출처 확인으로 구성된다. 대화형 요소가 지원되지 않는 환경에서도 따라할 수 있도록 모든 실습에 대체 경로를 넣었다.
